# Маруся

<h3 style="font-size: 24px;">Онлайн-платформа Маруся позволяет искать фильмы, а также добавлять их в избранное, просматривать трейлеры.</h3>

<h2>Описание</h2>
<h3>В приложении два основных экрана - главная и жанры: на главной пользователю предлагается случайный фильм, который он может обновить, а на странице жанров пользователь может выбрать любой жанр и посмотреть фильмы, которые относятся именно к нему.</h3>

<h3>На платформе реализован функционал регистрации и входа, так что залогиненный пользователь может перейти в личный кабинет, где он может посмотреть свою коллекцию избранного или данные об аккаунте, а также выйти из него.</h3>

<h2>Разработка</h2>
<h3>Приложение выполнено на React с типизацией Typescript, а также с использованием Redux Toolkit для управления состояниями. Кроме того, использованы такие библиотеки, как react-query для взаимодействия с API и react-router-dom для маршрутизации в приложении. Сборку приложения обеспечивает Vite.</h3>

<h2>Запуск</h2>
<h3>- Перейдите в папку cinema-guide;</h3>
<h3>- Установите зависимости командой `npm i`;</h3>
<h3>- Введите команду `npm run start` для запуска проекта.</h3>
